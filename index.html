    About SIPAT

    What SIPAT does

    SIPAT — Smart Identification and Portable Analysis Tool — uses a browser camera and a configured YOLO model to help field researchers capture, count, and provisionally classify mosquito larvae in water samples during vector surveillance work.

    Workflow

    Capture → Detect → Count → Identify → Analyze → Download results. Scan records are saved in this browser for later review; captured frames are not retained by the page.

    Model scope & limitations

    The selected species detector reports Aedes, Anopheles, or Culex. Other species may be missed or misclassified, so treat low-confidence results as uncertain and send ambiguous specimens for manual review. SIPAT is a research aid, not a diagnostic or regulatory instrument.

    YOLO model settings

    SIPAT now defaults to a published species detector for Aedes, Anopheles, and Culex. It runs in this browser using Inference.js. See the species dataset and model.

    The app is preconfigured with a shared Roboflow publishable key, so users do not need to enter one. Use only a publishable key here, never a private API key. Camera frames are analyzed in the browser and are not uploaded by this page.

    Manual review checklist

    Confirm the following before signing off on this detection record.

    • Bounding boxes align with visible larval bodies, not debris or bubbles.
    • Low-confidence detections (under 85%) have been visually double-checked.
    • Sample ID, site, and collection notes are complete and accurate.
    • Any ambiguous specimens are flagged in field notes for lab follow-up.
